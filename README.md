Woodie's Wild Expedition
A 2D platformer built in Processing where you play as Woodie, an adventurous robot who crashes and breaks into pieces. Help him recover his missing parts by exploring dungeons, defeating monsters, and unlocking hidden secrets.
Story
Woodie lost all of his parts — and where did all of them go? Set off on a quest through dangerous dungeons filled with creatures, traps, and hidden treasures to become whole again.
How to Play

Download and install Processing (free)
Download or clone this repository
Open the .pde file in Processing
Click the Run button

Controls

Arrow Keys / WASD — Move
Space — Jump

Levels
Level 1 — Reach the flag while defeating monsters in your way.
Level 2 — Avoid traps, collect a key, unlock a mysterious box, and discover what's hidden inside.
